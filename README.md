# Master KJ

An AI assistant starter project built with Next.js.

## Getting started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Notes

This is a starter template. The chat UI currently echoes messages back —
connect it to an AI model (e.g. the Anthropic API) to make it respond for real.
